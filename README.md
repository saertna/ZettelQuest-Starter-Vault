# ZettelQuest-Starter-Vault

## Short description

ZettelQuest‑Starter‑Vault is an Obsidian vault template created for the coaching program  
ZettelQuest: The Journey to Infinite Insights. It’s a beginner‑friendly Zettelkasten starter vault that Andreas uses in his group coaching — and anyone who wants to start a Zettelkasten can use it freely.

## Core purpose

- Provide a working, Obsidian vault structure and pre installed plugins so newcomers can start practicing Zettelkasten quickly.
- Provides a basic structure for orientation

## Who this is for

- Participants of the ZettelQuest coaching program.
- Anyone who wants a pre setup practical Obsidian vault to start a Zettelkasten.
## Quick highlights

- Vault contains a basic folder structure, templates, and pre-installed plugins for an easy start.
- Designed for daily capture (fleeting notes), literature notes, and evergreen / permanent notes (zettels)
- Reach out on [LinkedIn](https://www.linkedin.com/in/andreas-trebing/) if you want guided support in structuring and using your Zettelkasten.

## Get started — step by step

1. Clone or download this repository.
	1. the green button labed `<> code`
2. When dowloaded extract the zip file on your hard disk 
3. Open Obsidian, choose "Open folder as vault", and select *inside* of the downloaded and extracted zip the folder `ZettelQuest`.
4. Open the Starter Guide note `0 Onboarding` and follow the short introduction.


## Gamification

you can install the plugin [gamified pkm](https://github.com/saertna/obsidian-gamified-pkm) to add some gamification to your Zettelkasten for some extra motivation.
