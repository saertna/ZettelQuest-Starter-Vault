this file is for a quick on-boarding. You can delete it when done. 

The [[1 Startpage]] has the purposes to be your first entry level into your Zettelkasten. From here you go deeper into your Zettelkasten. *You can change it's name so it reflects what resembles for you the starting point. e.g. `nexus` or `Yggdrasil`.*

The [[2 Index - Zettelkasten]] is another entry point beside the [[1 Startpage]]. You can enter manually important corner notes to it, or let it build by using the tag `#index` on your notes which shall be found with the help of the index.

[[3 Index - pkm]] is the index for resources you might need and find again. Also here you can do an manual one, or an automatic one by using `#pkm/index` as tag. 

[[4 Inbox - Fleeting note]] is a view in which you get all unprocessed information you have put in your Vault. Only processed information travel in the Zettelkasten. 

Folder structure
- The vault is configured to store all attachments you pull into the vault in the folder `Attachments`
- All literature references are foreseen to be stored in the folder `Biblography`
- Excalidraw drawings are stored automatically in `Excalidraw`
- All new files get automatically the tag `#inbox` and moved to the folder `Inbox`. All files with tag `#inbox` are displayed in the file [[4 Inbox - Fleeting note]].
- When working on a specific project, the folder `Projects` is foreseen
- In `Tamplates` are all templates stored which you can use to format your notes with templates.
- The `Zettelkasten` folder is your actual Zettelkasten where your thoughts and insights are stored.
- The `pkm` folder is where you store references you might need. Like manuals, guidelines etc. 

Look around by starting with the [[1 Startpage]]. Then add your first note by hitting `ctrl + n`


You can use certain syntax for formatting, have a look at [[Markdown Formatting]]. You don't need all of it. From the [[Markdown Formatting#Basic Formatting|Basic Formatting]] it's quite sufficient when you only use [[Markdown Formatting#Links|Links]] and [[Markdown Formatting#Headers|Headers]].
